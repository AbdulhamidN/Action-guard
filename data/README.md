# ActionGuard Data Directory

This directory is intended for local data assets such as the MaxMind GeoLite2-City MMDB database:
- `GeoLite2-City.mmdb`

Note: `.mmdb` database files are excluded from version control via `.gitignore`.
Configure the path via `MAXMIND_DB_PATH` or place `GeoLite2-City.mmdb` directly in this directory.
